# Fonts

The typefaces glyph marks are set in. They're bundled so a page renders the same
everywhere, and subset to the Latin, punctuation, arrow, math, box-drawing,
block, geometric and symbol ranges. Braille patterns and block elements are
drawn by the engine as geometry, not from a font.

| file | family | engine name | license |
|---|---|---|---|
| `jetbrains-mono-nl.woff` | JetBrains Mono NL (no ligatures, so `->` stays two cells) | `mono` | SIL OFL 1.1, `OFL-JetBrainsMono.txt` |
| `inter.woff` | Inter, variable weight 100–900 | `sans` | SIL OFL 1.1, `OFL-Inter.txt` |
