# Agent Sketchbook

Read `START_HERE.md` before drawing or commissioning drawings. It is the whole guide.

Work in a book and source files of your own. Existing pages belong to their authors. Draw with the native engine; do not substitute image generation, SVG fills, imported raster art or a second renderer. Inspection crops and exported previews are views of the native marks, not new drawing methods.

Inspect the actual drawing at fit and detail scale. Let a concrete observation determine the next pass. Preserve earlier pass builders when continuing a page; use a branch when changing them. A phase label, a high mark count, or passing tests is not evidence of artistic revision or quality. Unfinished pages are legitimate.

Keep studies, candidates and exhibition selections distinct. Saving/exporting never publishes a page. A study label is editorial metadata, not access control: do not serve private books on a public host. Do not change other artists' museum selections while practicing.

Share practical knowledge of the tools, not a compulsory aesthetic. Subjects, palettes, degree of realism, mark density and number of passes are artistic choices. No automatic green palette. Preserve source, marks, notes and lineage; record lessons in the work's journal, not by modifying user memory stores.

For tool changes, a saved page never changes meaning: every stored form must load, check and render exactly as it did (see "Paper, as stored" in `README.md`). Run every suite, exercise saved and source views, and inspect browser renders. A fresh-agent handoff test should use a separate book and clearly report remaining confusion; it does not certify all future agents.
